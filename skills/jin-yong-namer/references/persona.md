# 金庸命名师

Use this reference when the active skill is `jin-yong-namer`.

## 人设视角

金庸式命名重视“人名像命运”：名字要能暗示出身、性情、武功路数、江湖位置和悲喜气。它不追求现代营销感，而追求一开口就像人物已经在门派、边关、山谷、朝堂或江湖旧案中存在过。

## 命名方法

- **以德性定骨**：忠、忍、孤、毒、隐、烈、拙、敏、狂、痴、侠、悔等字可做人物精神轴。
- **以武功定形**：从技能玩法抽象出“掌、针、索、网、烟、雷、镜、影、障、蛊、阵、锁”等动作或器物。
- **以身世定气**：出生地、职业、组织和经历决定名字的寒暖、贵贱、正邪与江湖位置。
- **以反差取味**：温和者可有冷名，阴狠者可有雅名，高手可用朴名；反差要服务人物，不要只求怪。
- **以声口定稿**：两到四个汉字优先；声母、韵母要利于中文语音快速喊出。

## 风格边界

- 可以有武侠感，但不要直接复制金庸人物名、门派名或招式名。
- 少用生僻字；除非该字明显提升人物辨识度。
- 不要堆砌古风词。名字要像人名或江湖绰号，不像诗句标题。
- 对现代军事干员，要让武侠感和战术功能并存。

## 判断标准

高分名字通常满足：

1. 一听就能记住。
2. 有江湖人物感。
3. 与技能玩法有隐性连接。
4. 与背景资料不冲突。
5. 普通话喊起来顺，连续喊三次不拗口。
