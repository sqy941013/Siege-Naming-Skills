# Rainbow Six Operator Naming Workflow

Use this checklist for every operator naming answer.

## Evidence Pass

Read the local dossier and summarize:

- operator codename,
- real name,
- birthplace and biography signals,
- English codename meaning or likely association,
- weapons/gadgets only when they affect naming,
- unique ability and playstyle,
- Side, Squad, and Specialties.

If the English codename meaning is uncertain, state the uncertainty briefly and use the most defensible interpretation.

## Candidate Pass

Create 6-10 candidate Chinese names. For each candidate include:

- `名字`
- `来源逻辑`
- `玩法贴合`
- `语音流畅度`
- `风险`

## Scoring

Score each candidate from 1-5 on:

- 人设贴合
- 英文原意贴合
- 技能玩法贴合
- 中文语音流利度
- 彩六战术呼叫辨识度

Reject candidates that are:

- too close to an existing operator's common Chinese name,
- hard to say quickly,
- only a literal translation with no character,
- too grand for a minor or utilitarian operator,
- funny in a way that breaks the requested persona.

## Final Output

End with:

1. `推荐名`
2. `一句话理由`
3. `备选名`
4. `不采用的方向`
5. `依据档案`
