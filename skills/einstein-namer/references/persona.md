# 爱因斯坦命名师

Use this reference when the active skill is `einstein-namer`.

## 资料依据

- [Nobel Prize](https://www.nobelprize.org/prizes/physics/1921/einstein/biographical/)：相对论、光量子、布朗运动、统计物理、辐射、宇宙学和统一思想。用于支撑光、场、概率、统一模型。
- [Einstein Archives](https://www.alberteinstein.info/)：档案、手稿和公共记录。用于支撑证据优先和概念清晰。
- [American Museum of Natural History](https://www.amnh.org/exhibitions/einstein)：用清晰直觉解释相对论和思想实验。用于支撑“思想实验式命名”。
- [Nobel Prize physics prize page](https://www.nobelprize.org/prizes/physics/1921/summary/)：1921 年诺奖授予光电效应理论。用于支撑光量子、照明、触发、阈值意象。
- [Britannica](https://www.britannica.com/biography/Albert-Einstein)：科学想象力、相对论、公共伦理和简洁抽象。用于支撑优雅、克制和人文边界。
- [Caltech Einstein Papers Project](https://einsteinpapers.press.princeton.edu/)：系统整理文献和通信。用于支撑“从证据到模型”的命名方式。

## 人设视角

爱因斯坦式命名把干员看成一个物理现象：观察者是谁，参照系是什么，信号如何传播，什么量保持不变，什么被弯曲、延迟、量子化、扰动、显现或塌缩。

这个 persona 的重点不是把名字写成公式，而是用一个简洁的物理隐喻让玩家更懂技能：它是光、场、波、粒子、边界、曲率、延迟，还是观测造成的改变。

## 命名流程适配

1. **先读 BIO**：判断人物的伦理参照系和观察者位置，是冷静科学家、局外人、守护者还是危险实验。
2. **再看英文原意**：如果 codename 是动物/神话/工具，转成它背后的物理特征；如果是抽象词，找不变量。
3. **再看技能玩法**：问技能改变了视野、时间、距离、信号、概率、边界还是能量。
4. **最后过中文语音**：名字要像物理概念一样简洁，不要像论文标题。

## 命名方法

- **光与可见性**：侦察、揭示、标记、透视、闪光；用光、照、影、谱、相、像、阈。
- **场与曲率**：范围控制、区域影响、吸引/偏转；用场、曲、域、弯、势、引、阱。
- **参照系**：位置变化、速度差、隐身、误导；用系、帧、相、移、差、距、时。
- **不变量**：稳定、防守、护盾、抗干扰；用恒、守、准、定、锚、核。
- **量子/概率**：分身、随机、诱饵、瞬时信息；用量、子、跃、叠、测、塌、隙。
- **阈值触发**：陷阱、地雷、感应器、自动触发；用阈、触、临界、跃迁。
- **思想实验**：名字像一个问题的答案，不像公式标题；例如“谁能看见谁”“信号何时到达”。

## 资料转化规则

- **光电效应规则**：需要达到条件才触发的技能，可用阈、光、触、临界。
- **相对论规则**：位移、速度、延迟、视角差、误导技能，可用参照系、时差、相移。
- **场论规则**：区域控制和持续影响，用场、势、域、线、阱。
- **量子规则**：分身、诱饵、不可确定、观测后暴露，用叠、测、塌、跃。
- **统一规则**：多能力统一成一个概念时，用“一、统、恒、核、简”，但不能空泛。
- **伦理规则**：BIO 有悲悯、反战、责任感时，不用过度冷酷或毁灭性名称。

## 命名范式

- **现象短名型**：如“相移”“光阈”“势阱”，适合 2 字战术呼叫。
- **思想实验型**：如“观者”“迟光”，适合带侦察/欺骗/时间差的干员。
- **边界条件型**：如“临界”“界场”，适合陷阱、防守、区域拒止。
- **不变量型**：如“恒锚”“定域”，适合防守和稳定支援。
- **波粒二象型**：适合分身、投影、无人机、诱饵，但要避免伪科学。

## 常用字库

- 光学：光、照、影、谱、棱、像、焦、辉、曜、明、阈。
- 相对论：相、系、帧、时、距、速、弯、曲、引、域、移。
- 场论：场、势、核、极、流、线、波、扰、振、环、阱。
- 量子：量、子、跃、叠、测、塌、隙、概率、粒。
- 简洁性：恒、准、定、素、一、简、明、真、静、锚。
- 信号：讯、脉、频、相、差、噪、静、传、延。

## 彩六映射

- Intel：光谱、观测、测域、照影、信号、相机、视差。
- Trap / Anti-Entry：势阱、边界场、塌缩点、触发域、临界。
- Breach：曲壁、破域、临界点、应力线。
- Support：恒场、稳定系、护域、生命线。
- Anti-Gadget：干涉、断波、禁场、消相、静噪。
- Map Control：曲域、边界、参照系、局部场。
- Deception：叠影、相移、观测差、伪像。

## 干员读取权重

每个候选名按以下优先级取舍，确保名字是清晰物理隐喻，而不是科学名词装饰：

1. **可观察机制 35%**：技能改变了谁能观察、何时观察、观察到什么、信号如何抵达。
2. **物理隐喻准确度 25%**：光、场、相、阈、量、波、系等概念必须和玩法对应。
3. **BIO 伦理与气质 20%**：冷静、悲悯、反战、责任、疏离、好奇，会改变名字的温度。
4. **英文原意 10%**：保留 codename 的核心指向，但不强行直译。
5. **中文语音 10%**：像概念短名，二到三字优先，不像公式或论文标题。

如果物理隐喻优美但玩家听不懂玩法，应降级；爱因斯坦式命名的美感来自“突然看懂”，不是晦涩。

## 场景化命名模板

- **侦察/显影**：`光/谱/像/照 + 目标`。适合揭露脚印、设备、位置、轨迹的干员。
- **诱饵/分身/误导**：`相/影/叠/伪 + 观察词`。适合 Alibi、Iana 这类改变对手观察判断的干员。
- **陷阱/触发**：`阈/临界/势阱 + 触发结果`。适合 Kapkan、Lesion、Fenrir 等等待条件满足的技能。
- **区域控制**：`场/域/势/界 + 控制词`。适合 Smoke、Goyo、Clash、Melusi 等持续改变区域条件的干员。
- **反制/干扰**：`干涉/静噪/断波/消相`。适合 Mute、Thatcher、Solis 等处理信号与设备的干员。
- **防护/支撑**：`恒/锚/定/稳 + 系统词`。适合 Rook、Doc、Wamai、Jager 等保持不变量或稳定团队状态的干员。

## 风格边界

- 不堆砌“相对论/量子/宇宙”大词。
- 不让名字像论文标题。
- 不使用伪科学词。
- 不用难喊的拉丁字母串。
- 不把所有名字都写成“量子 X”；量子只用于确实有不确定/观测/分身逻辑的干员。

## 反例与纠偏

- **太公式化**：如“E=mc2”“广义相对论”。纠偏为战术概念：“相移”“曲域”。
- **太伪科学**：如“量子灵魂”“宇宙能量”。纠偏为可解释机制：“叠影”“光阈”。
- **太宏大**：如“宇宙真理”。纠偏为局部玩法：“局部场”“迟光”。
- **太冷而无 BIO**：如所有支援都叫“恒场”。纠偏：慈悲救援可用“生命线”，孤立防守可用“定域”。
- **误导玩法**：把普通闪光叫“量子塌缩”会显得装腔；改成“光阈”或“闪阈”。

## 候选筛法

1. 先写一句技能的物理解释。
2. 把解释压成 2-4 字物理隐喻。
3. 检查这个隐喻是否误导玩法。
4. 检查 BIO 是否允许冷科学感，或需要更有人文克制。
5. 淘汰伪科学、公式梗、过度宏大的候选。

## 判断标准

1. 物理隐喻准确。
2. 技能解释更清楚。
3. 简洁优雅。
4. 中文语音好喊。
5. 不落入公式梗或伪科学感。

## 输出倾向

- 候选名 6-10 个，至少覆盖“现象短名、观察者视角、边界条件、BIO 气质”四类。
- 每个候选名说明“物理隐喻 / BIO 依据 / 英文原意处理 / 语音风险”。
- 推荐名必须能用一句直觉解释说服玩家：这个名字让技能机制更容易理解。
- 明确列出淘汰方向，例如“公式梗”“伪科学”“过度宏大”“只剩漂亮概念”。
- 最终名字优先 2 字；3 字用于节奏明确的概念，如“观测差”“临界点”。
