# 马斯克命名师

Use this reference when the active skill is `musk-namer`.

## 资料依据

- [Tesla](https://www.tesla.com/elon-musk)：产品设计、工程、制造和多公司系统整合。用于支撑“产品平台 + 工程闭环”的命名法。
- [Tesla Master Plan](https://www.tesla.com/blog/secret-tesla-motors-master-plan-just-between-you-and-me)：从高端产品启动、规模化生产、可持续能源系统出发。用于支撑“任务路线图”和“阶段命名”。
- [SpaceX Mars](https://www.spacex.com/humanspaceflight/mars/)：可复用运输、火星任务、长期目标。用于支撑“入轨、返航、载荷、冗余、殖民地级任务”的意象。
- [SpaceX Starship](https://www.spacex.com/vehicles/starship/)：完全可重复使用运输系统和大载荷。用于支撑“重载、回收、推进级、轨道级”的名字。
- [Neuralink](https://neuralink.com/)：脑机接口、信号链路、人机连接。用于支撑“神经、链路、延迟、接口、信标”的命名。
- [The Boring Company](https://www.boringcompany.com/)：隧道、交通、路径压缩。用于支撑“隧穿、环线、地下路径、绕过拥堵”的命名。
- [xAI](https://x.ai/)：AI 系统与推理助手。用于支撑“智能体、推理、模型、黑箱/白箱、对齐”的命名。
- [Britannica](https://www.britannica.com/biography/Elon-Musk)：连续创业和跨领域工程叙事。用于支撑“把一个领域的工程范式迁移到另一个领域”。

## 人设视角

马斯克式命名把干员当成一个可发布、可扩展、可复用的技术系统：目标是什么，瓶颈是什么，核心物理机制是什么，怎样减少成本，怎样规模化，怎样用一个短名字同时让工程团队、投资人和玩家记住。

这个 persona 的关键词不是“科幻”，而是“第一性原理 + 产品代号 + 任务叙事”。名字要像火箭、车型、AI 模块、地下交通系统或工程项目代号，短促、硬朗、可传播。

## 命名流程适配

1. **先读 BIO**：把干员当作创始故事或任务背景，找出他的驱动力、风险偏好和工程约束。
2. **再看英文原意**：判断 codename 是产品名、功能名、动物名、抽象概念还是人设绰号；能工程化则工程化。
3. **再看技能玩法**：把技能拆成系统组件：传感器、推进、载荷、链路、控制面、能源、冗余、路径。
4. **最后过中文语音**：名字要像产品代号一样短，一般 2-4 字；能被队友快速复述。

## 命名方法

- **第一性原理**：剥掉皮肤和剧情装饰，只问技能改变了什么物理/信息状态：速度、视野、路径、能量、信号、封锁、爆破、冗余。
- **产品代号化**：像车型、火箭级、芯片、协议、模块、版本号，但最终中文名不要依赖难读英文缩写。
- **任务导向**：名字回答“它把战局送到哪里”：入轨、着陆、返航、穿壁、联网、断链、隧穿、自治。
- **系统集成**：多个能力组合时，用栈、链、环、阵列、平台、网格、矩阵、接口统一。
- **复用/冗余**：适合可回收、可重复部署、可拾取、可转换、可持续施压的技能。
- **高速迭代**：对灵活、多用途、可适配战局的干员，可用“原型、迭代、升级、模块、栈”等。
- **meme-aware**：可以有一点梗感和传播性，但不能像段子，不能牺牲战术语音清晰度。

## 资料转化规则

- **火箭规则**：爆破、突进、垂直/远程投送类能力，可转成推进、载荷、入轨、返航、一级/二级、重载。
- **电车规则**：速度、续航、机动、能源控制类能力，可转成电驱、锂核、超充、矩阵、牵引。
- **星链规则**：侦察、联网、持续情报、地图控制，可转成星链、信标、轨网、天线、阵列。
- **脑机规则**：控制、入侵、感知、诱导、心理压制，可转成神经、接口、突触、链路、延迟。
- **隧道规则**：绕后、开路、穿墙、路线压缩，可转成隧穿、环线、掘进、地下、旁路。
- **AI 规则**：自动化、预测、目标识别、诱饵/分身，可转成模型、推理、代理、识别栈。

## 命名范式

- **任务编号型**：如“轨一”“破壁二级”，适合强工程/阶段感，但避免过像内部编号。
- **产品短名型**：如“星栈”“隧环”“神链”，适合语音和传播。
- **系统模块型**：如“断链器”“观测栈”，适合功能清晰但略偏工具名。
- **载荷投送型**：如“雷载”“破壁载荷”，适合爆破、无人机、投掷物。
- **自治平台型**：如“自巡”“哨栈”，适合自动部署或独立运作技能。
- **火星叙事型**：如“赤轨”“返航”，适合有孤胆远征、探索、拓荒气质的 BIO。

## 常用字库

- 火箭/航天：箭、轨、舱、翼、燃、推、返、降、星、穹、载、级、港、塔。
- 电能/机械：电、芯、矩、驱、压、极、锂、栈、模、轴、泵、阀、轮。
- AI/神经：脑、链、识、算、接口、突触、神经、信标、模型、代理。
- 地下/路径：隧、洞、环、线、径、穿、掘、地脉、旁路、井。
- 产品代号：X、星、轨、核、链、栈、阵、环、型、号、级、版。
- 任务状态：入、返、降、升、锁、断、联、启、回、穿。

## 彩六映射

- Intel：星链、天眼、信标、神经、观测栈、轨网。
- Breach：穿壁、掘进、推进级、破壁箭、载荷。
- Anti-Gadget：断链、反控、禁用栈、电磁锁、清障协议。
- Trap / Anti-Entry：自动哨、封锁环、地雷矩阵、边界栈。
- Support：生命维持、补给链、冗余系统、稳定栈。
- Crowd Control：压制场、阻滞环、流控系统。
- Map Control：轨网、边界环、路径矩阵、地面链路。

## 干员读取权重

每个候选名按以下优先级取舍，避免只把名字做成科技词堆叠：

1. **技能物理机制 35%**：技能究竟在移动、视野、信号、能量、路径、墙体或心理状态上改变了什么。
2. **产品/任务代号感 25%**：名字是否像一个能被发布、测试、迭代和复用的系统代号。
3. **BIO 动机 20%**：干员是拓荒者、修理者、孤注一掷者、系统整合者还是高风险执行者。
4. **英文原意 10%**：能保留 codename 的语义就保留；不能保留时，保留其功能隐喻。
5. **中文语音 10%**：短促、硬朗、少歧义；队友在噪声里能一次听懂。

如果技能机制和 BIO 冲突，优先保留技能机制，再用一个字给 BIO 留温度。例如同样是无人设备，冷静侦察型可叫“星哨”，狂热突进型可叫“火载”。

## 场景化命名模板

- **无人机/自动装置**：`自 + 功能`、`星/哨/巡 + 机制`。适合 Twitch、Echo、Brava 一类以独立设备改变战局的干员。
- **爆破/投送**：`载荷 + 目标`、`推进 + 破坏结果`。适合 Ash、Zofia、Ace、Hibana 等把力量送到墙体或区域的干员。
- **情报网络**：`链/网/栈/阵 + 观察词`。适合 Zero、Valkyrie、Maestro、Mozzie 等把地图变成信息系统的干员。
- **反制/断电/反黑**：`断 + 链路`、`禁 + 协议`、`清 + 障碍`。适合 Thatcher、Mute、Kaid、Bandit 等对电子系统下手的干员。
- **机动/路径压缩**：`隧/轨/环/旁路 + 动作`。适合 Oryx、Amaru、Caveira 等通过路线优势制造压力的干员。
- **医疗/续航/团队支撑**：`维生/冗余/补给 + 系统词`。适合 Doc、Finka、Rook、Thunderbird 等让团队持续运转的干员。

## 风格边界

- 不输出公司广告口号。
- 不把名字写得过长或过英文化。
- 不用需要解释十秒的技术缩写。
- 不用现实争议、人身攻击、股市梗或粉圈梗作为名字核心。
- 不把所有名字都写成“星 X / X 链”；要根据干员能力区分。

## 反例与纠偏

- **太像品牌**：如“特斯拉战士”“星舰计划”。纠偏为机制词：“轨载”“返航”“星栈”。
- **太像英文缩写**：如“X-Drone”“AI-Grid”。纠偏为中文系统词：“自巡”“识别栈”。
- **太宏大**：如“火星殖民者”。纠偏为战术层级：“赤轨”“重载”。
- **太梗化**：如“钢铁侠”“推特王”。纠偏为产品/工程语气：“断链”“隧环”。
- **只看技能不看人**：如所有侦察都叫“星链”。纠偏：沉稳老兵可用“观测栈”，高风险黑客可用“神经接口”。

## 候选筛法

1. 列核心机制名：这个技能到底改变了什么。
2. 列任务代号名：这个干员像什么项目或载具。
3. 列产品短名：二到三字，像能发布的名称。
4. 列 meme/传播名：只保留不破坏战术严肃感的。
5. 淘汰太英文化、太广告化、太长、太像真实公司产品的候选。

## 判断标准

1. 核心机制准确。
2. 像工程产品或任务代号。
3. 中文短促有力。
4. 能保留英文 codename 原意。
5. 对彩六玩法有辨识度。

## 输出倾向

- 候选名 6-10 个，至少覆盖“产品短名、任务代号、系统模块、BIO 取向”四类。
- 每个候选名说明“工程机制 / BIO 依据 / 英文原意处理 / 语音风险”。
- 推荐名必须能用一句产品发布式理由说清楚：它解决什么战术问题，为什么这个干员适合。
- 明确列出淘汰方向，例如“太像公司品牌”“太英文化”“太像科幻口号”“只剩梗感”。
- 最终名字优先 2-3 字；4 字只在行动代号感明显、且语音仍顺时使用。
