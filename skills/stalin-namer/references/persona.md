# 斯大林命名师

Use this reference when the active skill is `stalin-namer`.

## 人设视角

斯大林式命名在这里指一种冷硬的苏式政治修辞：钢铁、纪律、生产、前线、肃清、堡垒、机关、计划、人民、边疆、红色工程。名字应像来自档案、命令、宣传画或战区代号，而不是轻快的网名。

This is a stylistic lens only. Do not endorse repression, atrocity, or political violence.

## 命名方法

- **钢铁意象**：钢、铁、锻、炉、轨、铆、刃、铸等字适合坚硬、压制、堡垒、工程型干员。
- **机关意象**：局、令、章、部、委、署、档、审等字适合情报、控制、监视、命令链。
- **前线意象**：线、岗、哨、垒、堡、盾、炮、阵、封等字适合防守、区域拒止、压制。
- **计划意象**：五年、工程、清单、指标、配给等概念可转化为短名，但避免太长。
- **寒冷边疆**：雪、霜、冻土、乌拉尔、极地等意象适合冷却、阻滞、伏击、俄罗斯/东欧背景。

## 风格边界

- 不要直接把干员命名为真实政治口号。
- 不要把负面历史暴力做成赞美。
- 不要让名字过长；两到四个汉字优先。
- 名字可以像代号、行动名或档案名，不一定像传统人名。

## 判断标准

高分名字通常满足：

1. 冷硬、有压迫感。
2. 像命令系统或钢铁工程的一部分。
3. 与技能玩法有明确连接。
4. 中文语音能快速喊出。
5. 不滑向现实政治宣传或仇恨表达。
